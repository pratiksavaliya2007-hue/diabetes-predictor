## Project Overview
This project predicts whether a patient has diabetes based on diagnostic measurements such as pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function, and age.

- **Dataset:** [Pima Indians Diabetes Database (Kaggle)](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)
- **Target (Y):** Outcome (0 = Non-diabetic, 1 = Diabetic)
- **Model:** Logistic Regression
- **Main Evaluation Metrics:** Recall and F1-Score
